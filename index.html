Слайд 1

Что такое Git?

Git — программа, которая помнит все версии твоих файлов: текстов, картинок, кода.

Представь альбом с наклейками: каждый раз, когда ты что-то нарисовал, ты клеишь новую наклейку с датой. Git делает то же с файлами на компьютере.

Зачем: не бояться ошибок — всегда можно вернуться к старой «наклейке».

Слайд 2

Репозиторий — дом для проекта

Репозиторий (repo) — папка проекта, за которой следит Git.

Туда кладут всё из одной работы: рассказ, игру, сайт.

git init

«Git, этот проект — твой, запоминай изменения».

Слайд 3

Коммит — сохранённый снимок

Коммит — снимок проекта в момент времени, как чекпоинт в игре.

  1. Выбрать, что сохранить: git add .
  2. Подписать снимок: git commit -m "…"

Сообщение объясняет, что изменилось — как подпись под рисунком.

Слайд 4

Ветки — разные версии одной истории

Ветка — отдельная линия изменений. Главная часто называется main.

В main — готовая история, в новый-конец — пробуешь другой финал, не ломая основную.

git branch новый-конец
git checkout новый-конец

Понравилось — сливаешь ветки обратно в main.

Слайд 5

Делимся и работаем вместе

Git отправляет проект на сервер (GitHub) и забирает чужие изменения.

  • git push — отправить коммиты в облако
  • git pull — скачать изменения друзей
  • git clone — скопировать проект к себе

Перед работой — pull, после готового куска — commit и push.

Итог

Git — память проекта: репозиторий, коммиты, ветки и обмен с друзьями.

Ошибаться можно — старые версии не пропадают.
