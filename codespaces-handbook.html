Урок 4: Codespaces + FastAPI

Облачный редактор → терминал → сервер на порту 8000 → страница /docs

Code → Codespace → pip install → uvicorn → /docs

0 Что такое Codespaces?

GitHub Codespaces — VS Code в браузере и Linux-компьютер на серверах GitHub. Python можно не ставить дома: всё в облаке.

1 Открой Codespace

  1. Репозиторий на GitHub, например git-pages-for-kids.
  2. Зелёная кнопка Code → вкладка Codespaces.
  3. Create codespace on main — подожди 1–3 минуты.

Нет Codespaces? Попроси взрослого про лимиты аккаунта или повтори шаги локально с Python.

2 Папка с примером

В проекте уже есть:

codespaces-fastapi/
  main.py
  requirements.txt

Код сервера можно посмотреть в репозитории на GitHub в папке codespaces-fastapi/.

3 Установи библиотеки

Terminal → New Terminal, затем:

cd codespaces-fastapi
python3 -m pip install -r requirements.txt

4 Запусти сервер

uvicorn main:app --reload --host 0.0.0.0 --port 8000
ФлагЗачем
main:appфайл main.py, объект app
--reloadперезапуск при сохранении файла
--host 0.0.0.0доступ из браузера Codespaces
--port 8000номер порта

Терминал с uvicorn не закрывай — пока он работает, сервер живой.

5 Открой /docs

  1. Появится Open in Browser для порта 8000 — нажми.
  2. Или вкладка Ports → 8000 → открыть в браузере.
  3. В адресе добавь /docs в конец.
Swagger UI — FastAPI
GET /hello
GET /

Нажми Try it out → Execute — увидишь ответ сервера в JSON.

6 Задание

  1. Измени текст в main.py (например, своё имя).
  2. Сохрани (Ctrl+S).
  3. Снова вызови API в /docs.

Чеклист

Если не работает

  • uvicorn не найден — снова установи зависимости из codespaces-fastapi.
  • Страница не открывается — uvicorn запущен? Порт 8000 открыт во вкладке Ports?
  • Нет /docs — проверь, что в конце URL именно /docs.
