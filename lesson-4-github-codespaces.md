# Урок 4: GitHub Codespaces + FastAPI

Пошаговый урок для детей. Ты откроешь **облачный компьютер** прямо в браузере, запустишь маленький **сервер на Python** и увидишь волшебную страницу **`/docs`** — интерактивную документацию API.

Готовый код лежит в папке [`codespaces-fastapi/`](codespaces-fastapi/) этого репозитория.

**HTML-справочник на GitHub Pages:** [codespaces-handbook.html](https://nesrv.github.io/git-pages-for-kids/codespaces-handbook.html) (локально: [codespaces-handbook.html](codespaces-handbook.html))

---

## Шаг 0. Что такое GitHub Codespaces?

**Codespaces** — это VS Code в браузере + Linux-машина на серверах GitHub.

- Не нужно устанавливать Python на свой компьютер (но можно и локально — по желанию).
- Все файлы проекта — в **репозитории** на GitHub.
- Кнопка **Code → Codespaces → Create codespace** — и ты уже в редакторе.

Представь: ты заходишь в **космическую лабораторию**, где уже есть стол, инструменты и терминал.

---

## Шаг 1. Открой Codespace

1. Зайди в репозиторий на GitHub (свой или [git-pages-for-kids](https://github.com/nesrv/git-pages-for-kids)).
2. Нажми зелёную кнопку **Code**.
3. Вкладка **Codespaces** → **Create codespace on main** (или на своей ветке).
4. Подожди 1–3 минуты, пока откроется редактор в браузере.

Если Codespaces недоступен (лимиты аккаунта) — попроси взрослого включить billing или используй **GitHub Classroom** / учебный аккаунт. Альтернатива: установить Python локально и повторить шаги из терминала на своём ПК.

---

## Шаг 2. Загляни в папку с примером

В Codespace слева открой папку:

```text
codespaces-fastapi/
  main.py           — код сервера
  requirements.txt  — список библиотек
```

Если ты в **пустом** репозитории — создай эти два файла и скопируй содержимое из папки примера или из шагов ниже.

---

## Шаг 3. Установи FastAPI

Открой **терминал** в Codespace: меню **Terminal → New Terminal**.

```bash
cd codespaces-fastapi
python3 -m pip install -r requirements.txt
```

Должны установиться **FastAPI** и **uvicorn** (программа, которая запускает сервер).

---

## Шаг 4. Запусти сервер

В том же терминале:

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Что означают флаги:

| Флаг | Зачем |
|------|--------|
| `main:app` | файл `main.py`, объект `app` |
| `--reload` | перезапуск при изменении кода |
| `--host 0.0.0.0` | сервер слушает снаружи (нужно для Codespaces) |
| `--port 8000` | порт 8000 |

Внизу появится строка вроде: `Uvicorn running on http://0.0.0.0:8000`.

**Не закрывай** это окно терминала — пока оно работает, сервер живой.

---

## Шаг 5. Открой сайт и `/docs`

1. Codespace заметит порт **8000**. Появится всплывающее окно **Open in Browser** — нажми его.  
   Или: вкладка **Ports** (снизу или слева) → порт 8000 → иконка «открыть в браузере».
2. В браузере увидишь JSON: `{"message":"Привет из FastAPI! ..."}`.
3. В адресной строке добавь **`/docs`** в конец, например:  
   `https://xxxx-8000.app.github.dev/docs`

Это **Swagger UI** — интерактивная документация. Там можно нажать на endpoint **GET /hello**, **Try it out**, **Execute** и увидеть ответ сервера.

Ещё есть красивая страница **`/redoc`** — тот же API, другой вид.

---

## Шаг 6. Эксперимент (задание)

1. В `main.py` измени текст в `message`, например на своё имя.
2. Сохрани файл (`Ctrl+S`). Благодаря `--reload` сервер обновится сам.
3. Обнови `/docs` и снова вызови **GET /** или **GET /hello**.

Поздравляю: ты **разработчик бэкенда** — сервер отвечает по HTTP!

---

## Что внутри `main.py` (коротко)

```python
from fastapi import FastAPI

app = FastAPI(title="Мой первый API", version="1.0")

@app.get("/")
def read_root():
    return {"message": "Привет из FastAPI! Открой /docs"}

@app.get("/hello")
def say_hello(name: str = "друг"):
    return {"hello": name}
```

- `@app.get("/")` — «когда браузер просит главную страницу, вызови эту функцию».
- `name: str = "друг"` — параметр в URL: `/hello?name=Маша`.

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| `command not found: uvicorn` | Снова: `pip install -r requirements.txt` из папки `codespaces-fastapi` |
| Страница не открывается | Проверь, что uvicorn **запущен**; открой порт 8000 во вкладке **Ports** |
| `/docs` пустой или ошибка | Адрес должен заканчиваться на `/docs`, без лишних символов |
| Изменения не видны | Сохранён файл? Сервер запущен с `--reload`? |

## Итог

**GitHub Codespaces** даёт редактор и сервер в облаке. **FastAPI** быстро делает API и сам рисует **`/docs`**. Дальше можно добавлять новые пути (`@app.get("/cats")`), подключать базу данных — но это уже следующие уроки.

**Связь с прошлыми уроками:** репозиторий на GitHub (урок 1) → сайт на Pages (урок 3) → сервер в Codespace (урок 4).
