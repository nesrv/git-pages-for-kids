Справочник: GitHub Pages

Держи эту страницу открытой, пока настраиваешь свой первый сайт

Репозиторий → index.html → Settings → Pages → Ссылка готова

1 Создай репозиторий

  1. Зайди на github.com и войди в аккаунт.
  2. + → New repository.
  3. Имя латиницей, например my-first-site.
  4. Create repository.

2 Добавь главную страницу

Файл должен называться index.html и лежать в корне репозитория.

  1. Add file → Create new file.
  2. В поле имени напиши: index.html.
  3. Вставь свой HTML и нажми Commit changes.

Без index.html GitHub не знает, что показать на главной.

3 Включи GitHub Pages

  1. В репозитории открой Settings.
  2. Слева: Pages.
  3. Source: Deploy from a branch.
  4. Branch: main и папка / (root).
  5. Save.
Build and deployment
Source: Deploy from a branch
Branch: main / / (root)

4 Узнай адрес сайта

Собери ссылку по шаблону:

https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/

Пример:

https://nesrv.github.io/git-pages-for-kids/

Готовая ссылка также появится на странице Settings → Pages через несколько минут.

5 Обновляй сайт

  • Меняешь файлы → новый commit (или Upload) → подожди 1–2 минуты.
  • Обнови страницу в браузере (Ctrl+F5).

Чеклист «Я всё сделал»

Если не работает

  • 404 — подожди 10 минут; проверь, что Pages включён.
  • Не тот текст — открой именно тот репозиторий, где лежит твой index.html.
  • Нет стилей — загрузи папку css и проверь путь в <link href="css/...">.
