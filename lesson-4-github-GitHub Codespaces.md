# Урок 3: GitHub Pages — твой сайт в интернете

Пошаговый урок для детей. В конце у тебя будет **ссылка**, которой можно делиться с друзьями.

**Справочник с картинками шагов (HTML):** открой файл [github-pages-handbook.html](github-pages-handbook.html) в браузере или на опубликованном сайте:  
`https://<твой-ник>.github.io/<имя-репозитория>/github-pages-handbook.html`

---

## Шаг 0. Что такое GitHub Pages?

**GitHub Pages** — это бесплатный «домик в интернете» для твоих HTML-страниц.

- Ты кладёшь в репозиторий файл `index.html`
- GitHub показывает его как **настоящий сайт**
- Адрес обычно такой: `https://ник.github.io/название-репозитория/`

Представь: репозиторий — коробка с файлами, а Pages — витрина, где все видят твою главную страницу.

---

## Шаг 1. Аккаунт на GitHub

1. Зайди на [github.com](https://github.com) (лучше с помощью взрослого).
2. Нажми **Sign up** и создай аккаунт.
3. Запомни свой **ник** — он будет в адресе сайта.

---

## Шаг 2. Новый репозиторий

1. Нажми **+** → **New repository**.
2. **Repository name** — короткое имя латиницей, например `my-first-site`.
3. Можно поставить галочку **Add a README file**.
4. Нажми **Create repository**.

Это твоя **папка-проект** на GitHub.

---

## Шаг 3. Главная страница — `index.html`

Сайту нужен файл с именем **`index.html`** в **корне** репозитория (не в подпапке).

Минимальный пример:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Мой сайт</title>
</head>
<body>
  <h1>Привет! Это мой первый сайт на GitHub Pages.</h1>
</body>
</html>
```

**Как добавить на GitHub (через сайт):**

1. В репозитории нажми **Add file** → **Upload files** или **Create new file**.
2. Имя файла: `index.html`.
3. Вставь код → **Commit changes**.

---

## Шаг 4. Включить GitHub Pages

1. Открой репозиторий → **Settings** (вкладка сверху).
2. Слева выбери **Pages**.
3. В **Build and deployment** → **Source**: **Deploy from a branch**.
4. **Branch:** `main` (или `master`) и папка **`/ (root)`**.
5. Нажми **Save**.

Через 1–10 минут GitHub покажет зелёную ссылку: **Your site is live at …**

---

## Шаг 5. Проверь адрес

Формула адреса:

```text
https://ТВОЙ-НИК.github.io/ИМЯ-РЕПОЗИТОРИЯ/
```

Пример: ник `nesrv`, репозиторий `git-pages-for-kids`:

```text
https://nesrv.github.io/git-pages-for-kids/
```

Открой ссылку в браузере. Если видишь свою страницу — всё получилось.

---

## Шаг 6. Обновлять сайт

Каждый раз, когда меняешь файлы:

1. Сохрани изменения в репозитории (новый commit на GitHub или `git push` с компьютера).
2. Подожди минуту-две.
3. Обнови страницу в браузере (иногда **Ctrl+F5**).

GitHub Pages сам подхватывает новую версию `index.html`.

---

## Частые вопросы

| Проблема | Что проверить |
|----------|----------------|
| Сайт не открывается (404) | Pages включён? Ветка `main` и папка `/ (root)`? Прошло 10 минут? |
| Пустая или чужая страница | Есть ли `index.html` именно в корне репозитория? |
| Картинки не видны | Пути к файлам: `images/cat.png`, а не `C:\Users\...` |
| Стили не работают | Файл `css/style.css` залит в репозиторий? В HTML: `<link href="css/style.css" rel="stylesheet">` |

## Задание для практики

1. Создай репозиторий `hello-pages`.
2. Добавь `index.html` с заголовком и одним абзацем о себе.
3. Включи Pages.
4. Запиши готовую ссылку в тетрадь.
5. Открой [github-pages-handbook.html](github-pages-handbook.html) и отметь все пункты чеклиста.

---

## Итог

**GitHub Pages** = репозиторий + `index.html` + Settings → Pages → `main` + `/ (root)`.  
Дальше можно добавлять CSS, картинки и несколько страниц — как в нашем уроке про Git.
