# Урок 1: Знакомство с Git

Простой урок для детей — 5 слайдов.

---

## Слайд 1. Что такое Git?

**Git** — это программа, которая **помнит все версии** твоих файлов: текстов, картинок, кода.

Представь **альбом с наклейками**: каждый раз, когда ты что-то нарисовал или написал, ты клеишь новую наклейку с датой. Git делает то же самое с файлами на компьютере.

**Зачем:** чтобы не бояться ошибок — всегда можно вернуться к старой «наклейке».

---

## Слайд 2. Репозиторий — дом для проекта

**Репозиторий** (repo) — это **папка проекта**, за которой следит Git.

Туда кладут всё, что относится к одной работе: рассказ, игру, сайт.

Команда, с которой часто начинают:

```bash
git init
```

Она говорит: «Git, этот проект — твой, запоминай изменения».

---

## Слайд 3. Коммит — сохранённый снимок

**Коммит** — это **сохранение снимка** проекта в определённый момент, как **чекпоинт в игре**.

Ты делаешь шаги:

1. Выбрать, что сохранить: `git add .`
2. Подписать снимок коротким сообщением: `git commit -m "Добавил третью главу"`

Сообщение должно объяснять, **что изменилось** — как подпись под рисунком.

---

## Слайд 4. Ветки — разные версии одной истории

**Ветка** — это **отдельная линия изменений**. Главная ветка часто называется `main`.

Пример: в ветке `main` — готовая история, а в ветке `новый-конец` — ты пробуешь другой финал, не ломая основную.

```bash
git branch новый-конец
git checkout новый-конец
```

Если новый конец понравился — можно **слить** ветки обратно в `main`.

---

## Слайд 5. Делимся и работаем вместе

Git умеет **отправлять** проект на сервер (например, GitHub) и **забирать** чужие изменения.

| Действие | Простыми словами |
|----------|------------------|
| `git push` | Отправить свои коммиты «в облако», чтобы друзья увидели |
| `git pull` | Скачать то, что добавили другие |
| `git clone` | Скопировать чужой проект к себе и начать с ним работать |

**Правило для команды:** перед работой — `pull`, после готового куска — `commit` и `push`. Так никто не перепутает версии.

---

### Итог

Git — это **память проекта**: репозиторий, коммиты, ветки и обмен с друзьями. Ошибаться можно — старые версии не пропадают.
