Урок 5: HTML + FastAPI

Страница на Pages спрашивает сервер в Codespace через fetch

Pages (HTML) → fetch → FastAPI → JSON
GitHub Pages
Codespace :8000

1 Запусти API (урок 4)

cd codespaces-fastapi
uvicorn main:app --reload --host 0.0.0.0 --port 8000

Скопируй URL порта 8000 (без /docs).

2 CORS в main.py

Браузер блокирует запросы с github.io на другой домен, если сервер не разрешил. В проекте уже есть:

from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["GET"],
    allow_headers=["*"],
)

После правок сохрани файл — при --reload сервер обновится.

4 Код fetch (идея)

const url = `${base}/hello?name=${encodeURIComponent(name)}`;
const response = await fetch(url);
const data = await response.json();

Endpoint /hello возвращает {"hello": "…"}.

Чеклист

Если не работает

  • CORS — смотри консоль (F12), проверь middleware.
  • Failed to fetch — Codespace выключен или неверный URL.
  • Старая страница — Ctrl+F5 после push на GitHub.
